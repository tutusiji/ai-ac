# 漫剧工坊 · 全屏节点画布交互重构(ComfyUI 风格)设计文档

- 日期:2026-10-07
- 状态:待评审
- 范围:仅前端(`public/`);后端(`server.js`、`lib/`)零改动

## 1. 背景与目标

现有前端是 tab 式 SPA(项目内 6 个 tab:脉络/分镜台/角色/剧本/成片/日志),生产流水线(创意→脉络→分镜→角色图→分镜图→视频→配音→合成→封面)靠流程条 + tab 切换呈现,全局状态与单镜操作的关联不直观。

目标:把项目内交互重构为 **ComfyUI 风格的全屏节点画布**——流水线和镜头以节点卡呈现,连线表达生产流向,节点状态随 SSE 实时流动;原 tab 的编辑能力收进右侧详情面板,整体界面全屏化。

## 2. 已确认的决策(与需求方对齐)

| 决策点      | 结论                                                                  |
| ----------- | --------------------------------------------------------------------- |
| 节点粒度    | **双层**:第 1 层粗粒度流水线总览;第 2 层展开为场景分组 + 镜头节点     |
| 旧 tab 去向 | **画布为主,tab 移除**;编辑器收进右侧详情面板;脉络工作室保留为全屏浮层 |
| 画布引擎    | **方案 A:零依赖手绘**(SVG 连线 + DOM 节点卡,自实现平移/缩放)          |
| 全屏含义    | 画布占满视口 + 工具条按钮触发浏览器真全屏(Fullscreen API)             |

## 3. 设计原则

1. **画布是 project.json 的纯投影**:`buildGraph(project)` 纯函数派生全部节点与连线,不新增数据模型、不落库、不加后端接口。SSE → `refreshProject()` → 重算图。
2. **复用优先**:各 tab 渲染函数(`renderShots/renderChars/renderScript/renderFilm/renderStory`)保留原样,改作详情面板/浮层的内容源;所有交互沿用 `data-act`/`data-change` + document 级事件委托,零事件重接线。
3. **零依赖、无构建**:不引入任何第三方库,沿用经典 `<script>` 全局脚本模式与现有 CSS 变量主题。
4. **画布节点只读**:节点卡上不放可编辑控件(textarea/输入框),编辑一律进右侧面板——避免 transform 缩放下输入法/光标体验问题。

│   │ 创意 │──▶│  脉络    │──▶│ 角色图 │──▶│分镜图│──▶│ 视频 │─┐  │
│   └──────┘   └────┬─────┘   └────────┘   └──────┘   └──────┘ │  │

│                          ·  ·  ·   ← 点阵背景,随平移缩放移动     │

- 画布根节点 `position:fixed; inset:0`,工具条/详情面板为悬浮层(玻璃拟态,复用现有主题变量)。
- 工具条元素(左→右):返回首页、项目名(重命名)、运行状态灯 + ⏹停止、下一步芯片(复用 `nextStepOf()` 逻辑,点击直达对应节点/面板)、撤销/重做、成本芯片、日志、设置、真全屏切换、重置布局。
- 首页(项目列表)保持现有卡片式不变,仅进入项目后切换为画布。

## 5. 节点模型

### 5.1 第 1 层 · 流水线总览(默认视图)

8 个节点,串行链:

| 节点 kind | 标题   | 状态/计数来源                                    | 单击面板内容                                                                  |
| --------- | ------ | ------------------------------------------------ | ----------------------------------------------------------------------------- |
| `idea`    | 创意   | 有无 `p.script`                                  | `renderScript()`(创意/剧本编辑器)                                             |
| `story`   | 脉络   | 章节数/场景数/场景状态灯(复用 `sceneStatusChip`) | 场景列表 + 「打开脉络工作室」 + 「为未展开场景生成分镜」(`stage: storyboard`) |
| `chars`   | 角色图 | `x/n` 有设定图                                   | `renderChars()`                                                               |
| `panels`  | 分镜图 | `x/n` `panelStatus==='done'`                     | 场景列表(直达镜头层对应场景)                                                  |
| `clips`   | 视频   | `x/n` + `🔒 m/n 场景已锁`                        | 场景锁定列表 + 批量生成入口                                                   |
| `voice`   | 配音   | `x/n`(有台词且 `voiceStatus==='done'`)           | 配音说明 + 批量入口                                                           |
| `film`    | 合成   | `p.filmUrl` 有无                                 | `renderFilm()`(成片播放/下载/成本表)                                          |
| `cover`   | 封面   | `p.coverImageUrl` 有无                           | 封面预览 + 生成/重roll + 下载                                                 |

连线:`idea→story→chars→panels→clips→voice→film→cover`(生产顺序投影)。

节点状态色:灰=待做,蓝=运行中(`p.running===stage` 或条目 `pending`),绿=完成,红=失败,橙=跳过(`voiceStatus==='skipped'`)。运行中节点连线加流动虚线动画。

### 5.2 第 2 层 · 镜头图(双击「脉络」节点进入)

- **场景分组节点**:头部 = 场景名 + 状态灯 + 🔒锁定/解锁按钮 + 「🪄 生成本场景分镜」(未展开时)。网格布局(约 3 列换行)。
- **镜头节点**(场景分组内纵向排列):缩略图(`panelUrl`/`clipUrl`,无图占位)+ 第 N 镜 + 台词/画面摘要(只读)+ 四个工序 pips:
  - `[文]` 有分镜文本(镜头存在即绿)
  - `[图]` `panelStatus`
  - `[视频]` `clipStatus`(`animatic` 计为完成·动态漫)
  - `[音]` `voiceStatus`(`skipped` 显示橙)
  - pip 悬停浮出「重roll」小按钮(直接触发对应 `data-act="gen"`)。
- 分组节点的输出边汇入画布右侧的「合成」节点(`film`)。
- 「创意/角色图/封面」在镜头层不铺开,经工具条芯片或命令面板打开对应面板。

## 6. 交互规范

| 操作         | 行为                                                              |
| ------------ | ----------------------------------------------------------------- |
| 滚轮         | 缩放到光标(0.3~2.5 倍)                                            |
| 拖空白       | 平移                                                              |
| 拖节点头     | 移动节点,位置存 localStorage(按项目记忆)                          |
| 单击节点     | 选中(描边高亮)+ 右侧详情面板滑出                                  |
| 双击「脉络」 | 总览 ⇄ 镜头图 切换                                                |
| 节点内按钮   | 触发现有 `data-act="gen"` 等,SSE 实时反馈变色                     |
| Esc / 点空白 | 收起详情面板                                                      |
| Ctrl+K       | 命令面板(条目画布感知:展开场景 N、切换层级、按节点生成、重置布局) |
| 快捷键       | `1` 总览 `2` 镜头图;`N` 新建、`?` 速查、`U`/`Y` 撤销重做保留      |
| ⛶ 全屏       | `requestFullscreen()`/退出;拒绝时 toast 提示                      |

**URL 即状态**:`/project/:id/flow?view=overview|shots&scene=<id>&sel=<nodeId>`。刷新/后退/分享链接均可直达对应层级、展开场景与选中面板。

## 7. 工程实现

### 7.1 文件结构

```
public/
├── flow-graph.js   # 新增:纯函数层 buildGraph(project, settings) → {nodes, edges}
│                   #   零 DOM 依赖;尾部带 CommonJS 导出兼容,供 node --test 单测
├── flow.js         # 新增:画布引擎(视口/连线/渲染/局部补丁)+ 详情面板宿主 +
│                   #   脉络工作室全屏浮层宿主 + 底部日志抽屉 + 全屏切换
├── flow.css        # 新增:画布/节点/连线/面板样式(复用 CSS 变量)
├── app.js          # 改造:删除 tab 条/pipeline 横条;renderProject 重写为画布挂载壳;
│                   #   render*() 函数与事件处理、SSE、命令面板保留
└── index.html      # 改造:画布根节点 + 引入 flow-graph.js / flow.js / flow.css
```

### 7.2 画布引擎(flow.js,核心约 400 行)

- **视口**:状态 `{x, y, scale}`;世界容器 `transform: translate(x,y) scale(s)`,`transform-origin: 0 0`。滚轮缩放到光标点,钳制 0.3~2.5;空白 pointerdown 拖拽平移;节点头拖拽改节点坐标并同步相连连线。平移/缩放不触发任何 DOM 重建。
- **连线**:节点层下叠 `<svg>`,每条边一条 cubic bezier(`M x1 y1 C …`),端点取节点边缘端口锚点;`stroke` 用 CSS 变量;`.running` 类 → 虚线 + `stroke-dashoffset` 动画。
- **自动布局**:`buildGraph` 输出拓扑 rank;总览层左→右分列(列距 260、行距 140 级别);镜头层场景网格 3 列换行、组内镜头纵向排列。
- **位置记忆**:拖动覆盖自动布局,存 `localStorage['manju.flow.<pid>.pos']`(`{nodeId:{x,y}}`);读写均 try/catch,失败静默降级;工具条「重置布局」清空。
- **局部更新**:SSE 刷新后若节点 id 集合未变,按 `data-node-id` 就地补丁(状态类/计数/pip/边类);拓扑变化才整体重建世界层。详情面板独立于画布重渲染,保持打开状态并跟随数据刷新。

### 7.3 flow-graph.js 签名

```js
buildGraph(project, settings, view) => {
  view,
  nodes: [{ id, kind, title, status, counts, pips?, sceneId?, shotIdx?, ports:{in:[x,y偏移], out:[…]}, x, y }],
  edges: [{ from, to, fromPort, toPort, kind }]
}
```

`id` 稳定可预测(`idea` / `scene:<场景id>` / `shot:<场景id>:<idx>` 等),供位置记忆、局部补丁、URL `sel=` 参数使用。

## 9. 错误处理

- 生成失败:节点/边变红 + toast(现有机制);详情面板展示完整 error 与 hint(`api()` 已带 hint 字段);节点提供重试入口。
- SSE 断线:现有 `pollTimer` 轮询兜底不变;工具条状态芯片显示「重连中」。
- `buildGraph` 与 localStorage 读写均 try/catch:构图异常 → toast + 「重置画布布局」;存取失败静默降级。
- 锁定闸门仍由服务端强制(未锁场景批量生成视频直接拒绝),画布只呈现锁状态,不新增客户端闸门逻辑。
- Fullscreen API 被拒绝(无用户手势等)→ toast 提示。

- 实现阶段用 `/run` 启动并截图核对视觉效果。

## 11. 明确不做(YAGNI)

- 节点自由重连/用户自建工作流(流水线是固定 DAG,重连无语义)
- 框选多选、批量拖动、节点折叠分组(场景容器已承担分组)
- minimap、触控手势专项优化(基本可用即可)、协作光标
- 画布操作进撤销历史(节点位置不入项目历史)
- 任何后端/REST/SSE 改动、任何第三方依赖

## 12. 风险与开放问题

- **DOM 规模**:几十个镜头节点 + SVG 边在本项目量级下无压力,不做虚拟化;若未来单项目上百镜再议。
- **就地补丁与动画**:状态补丁不能重启 CSS 动画——补丁只改类名,不动已存在节点 DOM 结构。
- **命令面板条目终稿**:在实现计划中随画布 action 一起列全,spec 不锁死清单。
