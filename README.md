# 漫剧工坊 · Manju Studio(火山方舟版)

一个本地部署的 **AI 漫剧(动态漫/竖屏短漫剧)生产线**:从一句话创意到带配音、带字幕的竖屏成片,全流程自动化。

```
故事创意 ──▶ 分镜脚本 ──▶ 角色设定图 ──▶ 分镜图 ──▶ AI 图生视频 ──▶ TTS 配音 ──▶ 字幕烧录+拼接成片
             豆包文本      Seedream      Seedream     Seedance(可选)    edge-tts        本地 ffmpeg
```

## 平台选型结论(为什么是火山方舟)

对主流 AI 漫剧生产平台做了比价(2026-10 检索公开资料,约值):

| 平台 | 计费方式 | 单集成本(6镜×5s) | API 流水线 | 结论 |
|---|---|---|---|---|
| **火山方舟(本方案)** | 按量付费,无月费 | **≈ ¥2(480p) / ¥3.5(720p)** | ✅ 文本+图+视频一体 | **已选:文本/生图/视频统一接入,角色一致性靠参考图** |
| 即梦网页版 | 会员制,大额档 ≈0.1 元/秒 | ≈ ¥3 | ❌ 无公开 API | 便宜但纯手动,无法自动化 |
| 可灵开放平台 | 灵感值,约 0.3~1 元+/秒 | ≈ ¥4~8 | ✅ | 单价偏高 |
| Vidu API | 按量,<0.3 元/秒 | ≈ ¥2~3 | ✅ | 便宜,但文本/生图需另配、角色一致性弱 |

> 选型逻辑:漫剧是"文本+生图+视频+配音"多模态流水线,**单一平台打通三类模态、支持参考图角色一致性、无月费沉没成本**的平台综合性价比最高。月产量大时可叠加方舟 AgentPlan 包月(Small ¥40 起,文本+图+视频共享额度)。
> 单价为约值,以各官网实时价格为准。参考:什么值得买横评(post.smzdm.com)、新浪财经(finance.sina.com.cn)、CSDN 实测(blog.csdn.net)、国内14款图生视频工具对比(ai-bio.cn)、搜狐实测(m.sohu.com)。

## 快速开始

```bash
cd ~/CodeLab/manju
./start.sh          # 首次运行自动创建 .venv 并安装 edge-tts
# 浏览器打开 http://127.0.0.1:8787
```

### 配置方舟 Key(二选一)

1. **环境变量(推荐)**:`export VOLCENGINE_ARK_API_KEY=ark-xxxx` 后启动;或
2. **网页设置**:右上角「⚙ 设置」里粘贴 Key,保存到本地 `data/settings.json`(不出本机)。

不配置 Key 也能跑:进入**零成本演示模式**(内置兜底分镜 + ffmpeg 直绘占位分镜图 + 动态漫动效),用于体验流程。

### 接入 Agent Plan 套餐(推荐)

已订阅方舟 Agent Plan 的话,在「设置」页填入**套餐专属 API Key** 并保存,平台自动变成混合计费:

- **文本 + 生图走套餐端点** `https://ark.cn-beijing.volces.com/api/plan/v3`,套餐额度内 0 现金消耗;
  默认模型 `doubao-seed-2-1-lite`(剧本/分镜)+ `doubao-seedream-5-0-pro`(角色/分镜图),均可在设置页下拉更换(套餐内模型名用小写连字符,如 `glm-5-3-flash`)。
- **套餐权益不含视频模型**(Seedance 报 UnsupportedModel),视频继续走按量 Key;不想花视频钱就把视频引擎切「动态漫」。
- 套餐的 Doubao-Seed-TTS-2.0 在 plan v3 端点下暂无 REST 路径(`/audio/speech` 等均 404),配音仍走 edge-tts(¥0)。
- 设置页提供「文本」「生图」两个连通性测试按钮(生图测试会真实生成一张 512 测试图,耗少量额度)。

### 模型未开通怎么办

方舟模型需逐个开通。若日志/页面报 `ModelNotOpen`:到 [火山方舟控制台](https://console.volcengine.com/ark) → 模型广场 开通对应模型;或在「设置」里换成已开通模型。本机已验证开通的默认组合:

- 文本:`doubao-seed-2-1-turbo-260628`(备选 `deepseek-v4-flash-ga-260731` / `glm-5-3-flash-260828`)
- 生图:`doubao-seedream-4-0-20260415`
- 视频:`doubao-seedance-1-0-pro-fast-251015`
- 配音:edge-tts(免费,无需 Key;走微软 Edge 朗读接口)

## 生产流程:先脉络,后画面(反抽卡工作流)

**设计原则:AI 只产草稿 → 人修改 → 点「采纳」才写入;贵的生成全部加闸门。**

```
故事创意 ─▶ ①脉络工作室(纯文本,≈¥0.02/次)
             ├─ 走向 premise + direction(AI 起草骨架 → 人改 → 采纳)
             ├─ 章节 arcs(AI 拆章 → 改 → 采纳)
             ├─ 节拍 beats(AI 拆拍 → 改 → 采纳)
             └─ 场景 scenes(AI 拆场景 → 改 → 采纳)
          ─▶ ②分镜台:逐场景生成分镜(纯文本,可逐镜改台词/画面)
          ─▶ ③🔒 锁定场景分镜(闸门:锁定前批量生成视频会被直接拒绝)
          ─▶ ④角色图/分镜图(套餐额度)  ⑤视频(按量)  ⑥配音+合成
```

- 「脉络」tab 顶部有**流程条**:章节 → 节拍 → 场景,每个场景挂着状态灯(未展开/分镜n/图x/n/视频y/n),全局进度一目了然。
- 生成闸门在分镜台:**未 🔒 锁定的场景,批量生成视频会被服务端拒绝**(报"视频已加闸"),单镜重roll不受限。
- **封面图**:项目页头部「🎨 生成封面」——用故事核心冲突 + 最多 2 张角色设定图参考 + 剧集名艺术字,生成 1080×1440 竖版海报(套餐生图,≈¥0.2),首页卡片与成片页下载均使用它,可随时重roll。
- 旧项目(无脉络结构)自动迁移:存量镜头挂到「整集(旧)」场景,可继续生成,也可补充脉络后按场景重排。

### 双引擎:火山方舟 + 阿里云百炼(通义)

平台按能力独立路由供应商,设置页逐项切换:

| 能力 | 供应商(UI 开放) | 阿里侧实现(代码预留,UI 未开放) |
|---|---|---|
| 文本(脉络/分镜草稿) | **火山 AgentPlan 套餐**(豆包/DeepSeek/GLM/Kimi 任选,0 现金);可在设置切阿里通义(有免费额度) | `qwen-plus` / `qwen-max`(OpenAI 兼容端点) |
| 生图(角色/分镜/封面) | **火山 Seedream 5.0(套餐),固定** | 万相 `wan2.6-t2i` / `wan2.6-image`(带角色参考图,本地图自动上传临时 OSS)——已实现,开通阿里按量后可在 settings.json 打开 |
| 视频(图生视频) | **火山 Seedance(按量),固定** | `wan2.6-i2v-flash`(异步任务)——同上 |
| 配音 | **edge-tts(¥0),固定** | `qwen3-tts-flash`——同上 |

> 供应商策略:账号未开通阿里套餐,因此 UI 只在"文本"上提供阿里通义(免费额度)作为备用引擎;生图/视频/配音固定走方舟,避免误切产生按量费用。

接入方式:设置页「阿里云百炼」区填入**标准 `sk-` Key**(百炼控制台创建;`sk-sp-` Token Plan 团队版 Key 不适用于 API 调用),然后把各能力的供应商切到「阿里」即可,保存即生效;连通性可用设置页的测试按钮验证。

### 已从开源社区借鉴的工程细节

- **两阶段提示词润色链**(借鉴 [alibaba/lumenx](https://github.com/alibaba/lumenx),MIT):生成分镜图/封面之前,先用当前文本模型把草稿提示词改写成"多参考图引用式"(图1/图2 精确指代角色设定图),带回声检测(润色结果与草稿相似度≥0.93 时退回草稿)、失败降级不阻塞生图;设置页可开关(promptPolish)。
- **`[characterN:name]` 多参考图引用协议**(同源):分镜生成时自动把出场角色的设定图编号注入润色上下文,替代"名字模糊匹配"。
- **台词 hash 缓存**(同源 dialogue-hash 思路):台词/音色/配音引擎任一未变化时跳过重合成,重复点配音不再重复花钱。

### 对接 ComfyUI(规划中,建议跑阿里开源模型)

本机未部署 ComfyUI;规划做法:`lib/` 增加 `comfy.js` 适配器,设置页新增「生图引擎」开关(云 API / ComfyUI):
调用 ComfyUI 的 `POST /prompt`(提交工作流 JSON)→ 轮询 `GET /history/{id}` → `GET /view` 取图,
分镜图管线只需替换 `genPanelWithFallback()` 一个调用点(见 `lib/pipeline.js`)。

**推荐在 ComfyUI 里跑阿里开源模型**(与线上双引擎形成"本地免费/云端付费"梯度):
- **Wan2.2-I2V / T2V**:分镜图转视频的开源主力,权重从魔搭 ModelScope 下载;
- **Qwen-Image / Qwen-Image-Edit**:分镜图与封面,中文文字渲染强(标题艺术字可直接进图);
- 角色一致性:IPAdapter + 角色参考图工作流,替换现有的"角色设定图参考"机制。

### 旧六阶段说明(兼容保留)

1. **① 分镜脚本**:把创意交给 LLM,产出结构化分镜 JSON(画面描述/台词/说话人/运镜/时长)+ 角色表;分镜台上可逐镜手改。
2. **② 角色设定图**:每个角色生成一张全身立绘,作为后续所有分镜图的参考图 —— 保证跨镜头角色长相一致。
3. **③ 分镜图**:逐镜文生图,自动挂载出场角色的设定图作参考;出图后统一裁切为 864×1536 竖屏。
4. **④ 视频片段**(可选):每张分镜图作为首帧走 Seedance 图生视频(9:16);不想花视频钱就切「动态漫模式」,用 Ken Burns 缓推变焦,0 成本。
5. **⑤ 配音**:台词按说话人自动分配音色,免费合成;时长记录用于对齐。
6. **⑥ 合成成片**:每镜视频与配音取长者对齐(视频不足克隆尾帧补齐)→ 烧录台词字幕 → 拼接输出 `film.mp4`。

## 交互指南

- **下一步引导**:项目页顶部的「下一步」横幅按项目状态实时计算当前最该做的事(写创意 → 脉络 → 场景分镜 → 角色图 → 分镜图 → 锁定 → 视频 → 配音 → 合成 → 封面),点按钮直达并自动排队;
- **命令面板**:`Ctrl+K` 搜索并执行任何操作(切 tab、生成、锁定、撤销、打开项目、设置…),`↑↓` 选择 `Enter` 执行;
- **快捷键**:`1~6` 切 tab,`Ctrl+Z`/`Y` 撤销重做(脉络页),`U`/`Y` 任意页,`N` 新建项目,`?` 速查表;单键在输入框内打字时不触发;
- **统一确认框**:所有删除操作使用样式化确认(说明影响范围 + 提示可用 Ctrl+Z 撤销),Esc/点遮罩=取消。

## 常见问题

- **AuthenticationError**:Key 无效/过期,在设置页更新或换环境变量。
- **ModelNotOpen**:到方舟控制台开通该模型,或换已开通模型(设置页可一键测试文本模型)。
- **配音失败**:确认 `.venv` 存在(`./start.sh` 会自动建)且本机可访问微软朗读接口。
- **重新生成**:分镜台上每镜都有「重绘/重做视频/配音」按钮;分镜文案改动后保存即可按单镜重roll。
- **Key 安全**:`data/settings.json` 含明文 Key,仅本机使用,勿提交仓库/外传。
